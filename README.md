## 🎯 Proje Amacı
Bu proje, kullanıcıya rastgele üretilen bir sayıyı tahmin ettirmeyi amaçlayan basit bir oyunudur.

## 🛠️ Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript
- Java

## 🚀 Nasıl Çalıştırılır
1. Projeyi bilgisayarınıza indirin veya klonlayın
2. `index.html` dosyasını tarayıcıda açın
3. Oyunu oynamaya başlayın
