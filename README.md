# Sayı Tahmin Oyunu 🎯

Basit ve eğlenceli bir sayı tahmin oyunu.  
Kullanıcı 1 ile 100 arasında rastgele seçilen sayıyı tahmin etmeye çalışır.

## 🎮 Oyun Özellikleri
- 1–100 arası sayı üretimi
- Hatalı giriş kontrolü
- Önceden tahmin edilen sayıları engelleme
- Kalan hak sistemi
- HTML, CSS ve JavaScript ile geliştirilmiştir

## 🖼️ Oyun Görünümü
![Oyun Önizleme](screenshots/preview.png)

## 🚀 Nasıl Çalıştırılır
1. Projeyi indirin veya klonlayın
2. `index.html` dosyasını tarayıcıda açın
3. Oyunu oynamaya başlayın 🎉

## 🛠️ Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript
